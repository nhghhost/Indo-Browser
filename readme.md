# Indo Browser

Modern web browser built with Electron. Privacy-focused, no telemetry, with DRM support.

## ✨ Features

- 🚀 **Multi-tab browsing** - Full BrowserView implementation
- 🎬 **DRM Support** - Netflix, Disney+, HBO Max, Prime Video
- 🔒 **DNS-over-HTTPS** - Bypass Internet Positif (partial)
- 🌐 **Full Chromium engine** - Chrome 120 with latest security
- 🛡️ **Privacy-focused** - No telemetry, no tracking
- 🎨 **Modern UI** - Clean and intuitive interface
- 🔧 **DevTools** - Full Chrome DevTools (F12)
- 🌍 **Context Menu** - Right-click with Google Translate integration
